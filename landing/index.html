Sistema de punto de venta
para tu negocio

Administra ventas, productos, clientes y reportes desde una sola aplicación de escritorio. Sin servidores externos, sin suscripciones.

Descargar para Windows

Requiere Windows 10 o superior  ·  64-bit

🛒

Punto de Venta

Registra ventas, gestiona tu inventario de productos y lleva el control de tu caja.

🎮

Sistema SSCM

Control de cuentas, clientes, períodos, recargas y configuración de ventas SSCM.

📊

Reportes

Historial completo de ventas con filtros por período, tipo y usuario.

🔒

Múltiples usuarios

Crea operadores y administradores con accesos diferenciados por punto de venta.

Instalación en 3 pasos

  1. 1
    Descarga el instalador

    Haz clic en el botón de descarga y guarda Mercurio-Setup.exe.

  2. 2
    Ejecuta el instalador

    Abre el archivo descargado y sigue las instrucciones del asistente.

  3. 3
    Inicia sesión

    Abre Mercurio desde el escritorio. Usuario: admin — Contraseña: admin123
